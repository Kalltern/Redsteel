# Changelog

Notable changes to the Redsteel system. Versions match the `release-*` tags on
GitHub.

## Unreleased

## 0.15.0

- Specialisations automated: Champion, Hoplite, Warden, Vanguard, Skirmisher,
  Ranger and Grimm; Half Pirouette automation
- Zephyrai racial perks; trait choices and Hated Enemy
- Material bonuses for weapons and gear; makeshift weapons
- Character creation: skill screen, starting defaults and a refreshed UI
- Teacher lessons tracker for specialisation teachers; learn flow updates
- Compatible weapon tooltips; reroll tuning
- Combat: a turn starts with Move already declared (unless next to an enemy),
  and players can no longer drag tokens in combat without a declared movement
- Rooted sets movement to 0 and blocks Dodge; Speed and initiative are kept
- Strike spells no longer remove weapon enchantments such as Dark Weapon
- NPCs roll their automatic defense against a fumbled attack
- Extended Lunge is refused through an occupied hex

## 0.14.1

- Version bump release

## 0.14.0

- Miracle casting and the miracle creation flow
- Servant of the Sword and Weapon Master specialisations automated
- Specialisation upgrades wired; stance user experience improved
- Compact skills ledger with a defense view
- Versus Test follow ups, stances and hotbar updates
- Fixed advantage forfeit and head shot boons

## 0.13.0

- Overwatch, size tags and reaction follow ups
- Cheat Death and forced movement
- Initiative tie breaks, ability movement and explosives
- Action economy, movement settings, sneak attacks and positioning
- Spell descriptions redesigned across schools; critical failure bonus rework
- Learn window: school colours, icon marks and a Spells category
- Expanded specialisation automation
